# hybridbyben.com

Home site for Hybrid_by_Ben. GitHub Pages serves `site/` at `hybridbyben.com`,
and other repos with Pages turned on (and no custom domain of their own) appear
under it by path:

| Path | Repo |
|---|---|
| `/` | this repo |
| `/baseline/` | `brodeurbenjamin/baseline` |
| `/tickets/` | `brodeurbenjamin/tickets` (planned) |

To add a tool: turn on Pages in its repo, leave its custom domain empty, and
add a card for it to `site/index.html`.
